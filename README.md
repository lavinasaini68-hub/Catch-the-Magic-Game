# 🎮 Catch the Magic

### ✨ Catch it. Score it. Level up!

**Catch the Magic** is an interactive browser-based catching game developed using HTML, CSS, and JavaScript. The game features multiple exciting themes, dynamic difficulty progression, animated effects, sound, and an engaging scoring system.

🌐 **Live Demo:** https://lavinasaini68-hub.github.io/Catch-the-Magic-Game/

---

## 🎨 Game Themes

Explore different gaming environments:

- 🎃 Halloween
- 🏀 Basketball
- ⚽ Football
- 🏓 Pickleball
- 🏸 Badminton
- 🚀 Space

## ✨ Features

- **Multiple Themes:** Choose from six different game environments.
- **Dynamic Difficulty:** Falling speed increases after every successful catch.
- **Level Progression:** New levels introduce more falling objects.
- **Scoring System:** Earn points by catching objects.
- **Lives System:** Avoid missing objects to keep playing.
- **Sparkling Trails:** Enjoy glowing trails and animated visual effects.
- **Background Music:** Theme-based background music and sound effects.
- **Halloween Customization:** Change between different Halloween objects during gameplay.
- **Pause & Resume:** Pause the game whenever needed.
- **Main Menu Navigation:** Return to the main menu while playing.
- **Badges & Streaks:** Enjoy additional gameplay rewards.

## 🎯 How to Play

1. Open the live game.
2. Select your preferred theme.
3. Start playing.
4. Catch the falling objects to earn points.
5. Increase your score and progress through levels.
6. Watch out as the game becomes more challenging!
7. Try to achieve your highest score.

## 🚀 Run Locally

To run the game on your computer:

1. Clone this repository:

   ```bash
   git clone https://github.com/lavinasaini68-hub/Catch-the-Magic-Game.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your browser.
4. Start playing!

No additional installation is required.
